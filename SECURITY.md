# Security Policy

## Reporting a vulnerability

If you find a security issue in the NextScrum Specs Kit, please report it
privately rather than opening a public issue.

Use GitHub's private vulnerability reporting: open the repository's **Security**
tab and choose **Report a vulnerability**. We will acknowledge the report,
investigate, and coordinate a fix and a disclosure timeline with you. Please do
not disclose the issue publicly until a fix is available.

## Scope

This project is a development methodology kit: documentation, Node-based audit
scripts, git hooks, and a static documentation site. The most relevant concerns
are the audit scripts and git hooks (which run in a contributor's environment)
and the dependencies they pull in. Reports about those are in scope.

Issues in third-party dependencies should be reported to their upstream
projects, though a heads-up here is appreciated.

## Supported versions

The latest released version receives security fixes.
